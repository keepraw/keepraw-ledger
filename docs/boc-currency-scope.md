# AUD-012：中国银行账户与币种范围

BOC PDF 的账户类型行明确标识「人民币/RMB」「美元/USD」「港币/HKD」；明细标题明确标识对应币种。解析器保留每个识别到的汇总组件的真实币种，不做汇率换算。

当前 Statement 仍以人民币账户作为主对账范围：只有一个人民币明细账户，且账户标题卡尾号匹配、人民币汇总行唯一时，才能填入用于对账的余额与收支。不同账户即使所有金额相同也不能相互代用；两个候选汇总即使数字一致也不能据此消歧。卡片总览只在主账户已确定后提供同一卡的最低还款额，不再补造缺失的币种余额。

没有可靠人民币汇总、账户标题无法识别、多个同账户人民币汇总或币种标记冲突时，主汇总字段留空，由现有对账器报告信息不足并进入待复核。可识别的其他汇总保留在 Statement summary.components 中，标签注明尾号和未用于人民币对账；原 PDF 附件由既有导入链保存。无法识别币种的原始行仍可从附件追溯，不猜币种。

已明确标识 USD/HKD 的明细保留各自币种与符号，不进入 CNY 明细合计。单独只有外币汇总时，本次不提供完整外币账户对账。当前账户定位依赖已支持布局的卡尾号标题和账户类型表头；新模板或无法消歧的布局需要人工审核。

测试包括三种汇总的六种排列、缺失人民币汇总、币种冲突/缺失、其他账户同额、同账户重复汇总、USD/HKD 明细、反向坐标轴，以及生成真实 PDF 字节经 pdf.js 提取、原生上传、IndexedDB 持久化、对账、重载和页面显示的浏览器链路。Golden、其他银行的币种规则和共享对账公式均未改变。
